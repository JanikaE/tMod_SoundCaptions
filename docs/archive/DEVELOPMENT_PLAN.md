# Sound Captions 开发与验收归档

已完成首版开发，已确认 S01 至 S12 全部通过游戏内验收。

| 阶段 | 完成内容 | 状态 |
| --- | --- | --- |
| S01 | 客户端模组可构建与加载，提供双语配置和可重绑的编辑快捷键。 | 通过 |
| S02 | 捕获本机已接受的音效播放，区分资源、字幕和音量身份。 | 通过 |
| S03 | 验证标准音乐播放及音效、音乐的独立音量控制链路。 | 通过 |
| S04 | 显示实时音效字幕，按声音族合并并标出左右方向。 | 通过 |
| S05 | 独立显示背景音乐字幕，支持切曲短显和持续显示。 | 通过 |
| S06 | 支持外观配置、分辨率与 UI 缩放适配、居中排版及渐隐。 | 通过 |
| S07 | 支持编辑模式、布局拖动与缩放、字幕选择和详情查看。 | 通过 |
| S08 | 支持按音效调节音量、静音、恢复默认和保存。 | 通过 |
| S09 | 支持逐曲音量和静音，正常播放与淡出沿用同一曲目的设置。 | 通过 |
| S10 | 集中管理已调整音量，支持搜索、保存和恢复，布局单独存放。 | 通过 |
| S11 | 完成原版音频清单和双语映射，提供模组名称回退及兼容注册。 | 通过 |
| S12 | 支持客户端独立联机，提供压力测量并完成全功能回归，开发诊断默认关闭。 | 通过 |

后续规格以根目录的[设计文档](../../DESIGN.md)为准。日常操作见[玩家指南](../../README.md)，原版音效与曲目见[原版音频映射清单](../VANILLA_AUDIO_CATALOG.md)。
