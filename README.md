# Sound Captions 玩家指南

[English](README_EN.md)

Sound Captions 是 Terraria/tModLoader 的客户端字幕模组。它把本机听到的音效写成字幕，并用单独一行显示当前背景音乐。基线为 Terraria 1.4.4.9 / tModLoader 2026.09.3.1 stable。

## 字幕和布局

- 音效和音乐字幕分别开关。默认持续 3 秒，结束前渐隐。同一种音效再次播放会刷新时间。箭头指向相对本机角色的左右方向。全局声音和水平方向距离低于阈值的声音不显示箭头。
- 在「模组配置 → Sound Captions → 字幕设置」调整字号、字色、背景透明度、显示时间和方向阈值。音乐可以设置为「仅切曲时显示」或「持续显示当前曲目」。
- 默认按 **F9** 进入编辑模式。拖动标题栏移动，拖动角落手柄缩放，滚轮浏览仍有效的音效。快捷键可在游戏的按键设置重绑，已保存的绑定会继续使用。Shift+F9 仍用于切换原版灯光。再次按快捷键退出，也可用 Esc 逐层退出详情和编辑模式。

## 独立音量

- 在编辑模式点击音效条目或「当前曲目」，用滑块、百分比输入框、静音或恢复默认按钮调节 0%～200% 的单项音量。数字输入用 Enter 保存、Esc 取消。0% 静音，100% 恢复默认，高于 100% 增强音量，实际幅度受音频后端限制。
- 在「字幕设置」页底的「已调整音量」搜索和编辑已保存的音效及音乐。集中编辑完成后按配置页的「保存」。恢复全部音量需要确认。
- 字幕布局在独立的「字幕布局」配置中保存。音量设置会跟随当前客户端，隐藏字幕后仍然生效。

## 联机和兼容

- 安装在需要字幕的客户端即可。服务器上的模组要求仍由该服务器决定。每个玩家使用各自的字幕和音量设置。
- 支持标准 tModLoader 播放链路。绕过该链路的第三方播放器需要兼容适配。音乐资源包替换音频后沿用原曲名，可由兼容模组注册显示标题。
- [原版音频清单](docs/VANILLA_AUDIO_CATALOG.md)列出原版字幕覆盖范围。开发诊断默认关闭，可在字幕设置中临时开启。
